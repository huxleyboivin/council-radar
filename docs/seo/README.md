# Semrush data (exported November 2026)

Saved from Semrush before the subscription ended on November 26, 2026. All volumes are Google Canada monthly averages; "kd" is Semrush keyword difficulty (0–100). Rows with 0 volume were left out of `council_keywords.csv`.

| File | What it is |
|---|---|
| `council_keywords.csv` | "<council> council", "... council meeting" and "... council agenda" for the 150 councils we read |
| `topic_keywords.csv` | Topic searches (LT2, IESO, solar, wind, battery, nuclear, agrivoltaics, landowners) and the page meant to rank for each |
| `serp_competitors.csv` | Top 10 Google results for the main topic searches |
| `link_prospects.csv` | Sites that link to similar Ontario energy resources, with outreach status |
| `rankings_*.csv`, `audit_*.csv` | Final position tracking and site audit snapshots (added November 25) |

## Final export (November 25, 2026)

- `rankings_2026-11-25.csv`: all 37 tracked keywords, Nov 21–25, for getcouncilradar.ca, poweradvisoryllc.com and blg.com. First rankings for us: "municipal support resolution" #9, "municipal support confirmation" #14, "council radar" #19.
- `organic_2026-11-25.csv`: what Semrush's index shows us ranking for (Ottawa and Kingston council pages).
- `backlinks_2026-11-25.csv`: no backlink data yet.
- `audit_2026-11-25.csv`: last site audit (0 errors) and what was done about each issue.
- `keywords_2026-11-25.csv`: nuclear, "city of X council meetings", regional council and mayor searches.
